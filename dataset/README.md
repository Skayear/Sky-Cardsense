# dataset/

Imágenes de referencia y metadata (JSON) de las cartas usadas para el matching de reconocimiento. Empieza con el mazo propio (Lucy Dressrosa Red/Blue, Blue Buggy) antes de escalar a todo el card pool.

Las imágenes y pesos de modelo pesados no se versionan en git (ver `.gitignore`); se documenta acá el proceso de obtención/regeneración del dataset.

Ver [Fase 2 — Visión por computadora (MVP)](https://github.com/Skayear/Sky-Cardsense/issues/2) y [Fase 5 — Robustez y escalado](https://github.com/Skayear/Sky-Cardsense/issues/5).
