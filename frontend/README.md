# frontend/

App web (React/Canvas) que consume el WebSocket del backend y dibuja el overlay (vida, DON, referencias de keywords) sobre la mesa. Incluye la pantalla de calibración cámara→proyector.

Ver [Fase 4 — Frontend / Proyección](https://github.com/Skayear/Sky-Cardsense/issues/4) y [`docs/architecture.md`](../docs/architecture.md).
